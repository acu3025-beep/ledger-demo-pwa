Ledger DEMO — zelfstandig prototype

Alle 60 transacties en rekeninggegevens zijn fictief. Geen verbinding met een bank. Het leeuwsymbool is een eigen illustratie en geen officieel banklogo.

Open index.html voor een lokale preview. Klik op Betaalrekening om transacties te openen. De zoekknop opent zoeken en filters. Zoek op 1050 of 1.050,00 voor 12 resultaten. Klik op een transactie voor details. Overige acties tonen een demonstratiemelding.

Voor installatie op iPhone: plaats alle bestanden op statische HTTPS-hosting. Open de URL in Safari en kies Deel > Zet op beginscherm. De ZIP zelf is geen installeerbare app. Wacht tot de melding 'Offline versie gereed' verschijnt voordat u offline test. Wissen van browsergegevens kan de offline cache verwijderen.

Lokale server (Node.js): node serve.cjs
Open http://localhost:8080 op dezelfde computer.
Geen installatie van pakketten nodig.
